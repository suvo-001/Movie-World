# 🎬 MovieWorld

MovieWorld is an **AI-powered movie recommendation system** built with Python and Streamlit. It recommends similar movies using movie information such as genres, keywords, cast, director, and overview.

## ✨ Features

* 🎬 Movie recommendations
* 🔎 Content-based filtering
* 🖼️ Movie posters
* ⭐ Movie ratings
* 🏷️ Genres, year & runtime
* 📝 Movie details

## 🤖 Machine Learning

* **TF-IDF** — converts movie content into numerical features.
* **Cosine Similarity** — finds movies with similar content.
* **Random Forest Regressor** — used as a supervised machine learning component.

## 🛠️ Tech Stack

**Python • Pandas • NumPy • Scikit-learn • Streamlit • Joblib**

## 📊 Dataset

**TMDB 5000 Movies Dataset**

## 🎯 Objective

To build a practical movie recommendation system using **machine learning, text processing, and content-based filtering**.
